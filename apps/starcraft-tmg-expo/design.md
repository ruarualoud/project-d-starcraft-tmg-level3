# StarCraft TMG 军表助手 - 界面设计

## 设计理念

本App以星际争霸的深空科幻风格为核心视觉语言，采用深色主题（深蓝/黑色背景配合霓虹蓝/绿/紫色高亮），模拟星际争霸游戏中的指挥中心界面。所有交互均针对移动端竖屏单手操作优化。

## 屏幕列表

### Tab 1: 数据库（单位浏览）
展示所有阵营的单位卡、战术卡、阵营卡。顶部阵营切换（Terran/Zerg/Protoss），搜索栏，分类折叠列表（阵营卡/单位卡/战术卡）。点击单位展开详情（属性、武器、升级、关键词）。

### Tab 2: 军表（Army Builder）
军表创建和管理的核心页面。顶部显示资源概览（矿物/气体/指挥点/补给/槽位）。分步骤流程：选阵营卡 → 选战术卡 → 编入单位 → 选任务/部署。底部军表列表管理（新建/加载/删除）。

### Tab 3: 工具箱
包含三个子功能：骰子投掷器（支持多种骰子、批量投掷、历史记录）、伤害计算器（选择攻击单位和目标单位，计算期望伤害）、对抗期望分析（A vs B，显示各概率事件的期望值和可选特性影响）。

### Tab 4: 比赛
比赛设置和记录。导入双方军表，设置任务条件，逐回合记录（伤害、击杀、得分、任务完成情况），最终统计汇总。

### Tab 5: 设置
数据管理（在线更新/导入数据包）、军表导入导出、关于信息。

## 关键用户流程

### 创建军表
选择阵营 → 设置矿物上限 → 选择阵营卡（解锁槽位）→ 选择战术卡（消耗气体）→ 编入单位（消耗矿物和槽位）→ 为单位选择升级 → 保存军表

### 分享军表
打开军表 → 点击分享 → 生成固定格式文本 → 复制到剪贴板 → 对方粘贴文本导入

### 伤害计算
选择攻击方单位 → 选择防御方单位 → 系统计算命中概率、伤害期望 → 显示各种特性组合下的结果

### 比赛记录
新建比赛 → 导入/选择双方军表 → 每回合记录战斗结果 → 记录得分和任务 → 查看比赛统计
