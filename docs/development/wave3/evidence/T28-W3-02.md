# T28-W3-02 发布版本与稳定能力ID

状态为in_progress。01真实来源及验证作为前置证据复用。

## 原因和方案

现有能力IR使用record/payload哈希及数组位置生成身份，调价与重排会改变无关能力的ID。正式产品工厂仍固定旧来源。建立显式能力语义登记表，来源定位由每次编译确定，运行时身份由持久登记表提供。发布解析器持有一组明确数据和组件引用，按用途检查依赖，绑定后从所选发布恢复。

本轮静态代码及真实候选探测发现Bile Launcher的Indomitable缺activation标签，当前IR编译被拒。源文是While Engaged条件修正，在登记表按原文声明passive分类，执行仍由后续family接线承担。
