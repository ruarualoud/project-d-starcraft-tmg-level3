# Wave3 正式对战增量验收执行细则

适用 Ticket28 / T28-W3-11。验收单位是一个可复核的功能场景。结算后取得行动权并能恢复，即可结束该场景。500 分与 2000 分沿用各自合法开局，优先从已有签名断点取证。

| 顺序 | 执行 | 通过条件 |
| --- | --- | --- |
| 1 旧功能与差分 | 对齐上一发布的定义、冻结字段、适配器和消费者。按定义归并已有正式军表证据。对实际变动分别查价格、武器显示和使徒投影。 | 列出已选入正式军表的定义、仅有映射的定义、实际变更及其产品证据。价格按适用单位规模读取，行动效果以实际消费者为准。 |
| 2 近战与控制 | 从 Standard 的已接入军表取一个攻击方和两个合法近战目标，由人工席位分配同一批攻击，沿正式 Room 提交。 | 记录目标、分配、伤亡、人口和控制读数、行动权与冷恢复。逐项标识本次实测和既有证据。 |
| 3 特殊进场 | 列出 500/2000 两列，对折跃、运输入场、生成、特殊进场分别定位合法军表、席位签名和保存后的棋位。 | 每格给出对应场景、规模与回执。依军表或卡牌互斥的动作使用独立短分支。 |
| 4 工具和战桌 | 在同一版、同一棋位交叉读取人工战桌和实战查询。分开核对正式写表、固定表计划、Teach 的发布绑定，以及终局/重连接口。 | 写明双方实际通过的产品入口、可比字段和任何未覆盖项。原生设备单独登记。 |

旧功能可继承的依据是相同规则事实、相同消费者和可追溯的旧执行证据。只找到同名记录时保留为待核；有费用或文本差分时逐条说明影响。签名的用/弃分支可复用同一前缀。每个新增动作只执行一次；发生异常时保留首个失败、产品返回与断点，再决定修正范围。

结果分别登记组件、正式 Match 和 Wave3 大项。只有列表所列必要子边界全部满足，才增加对应分子。
