## 后续交付顺序

1. **同版工具和 Skill。** 对受影响的 MCP 查询用房间原子对照，核对合法、明确拒绝、条件未知及实际结果。整理规则、种族、对抗、地图任务、写表、Plan/Teach 与副官的版本来源。Wave3 已有 17 份目标 Skill、70 个准备输入；Wave4 先算依赖命中数。旧包留给旧房，未变章节可复用。离线工程可以先做，模型生成与真实消费等用户指定模型。
2. **AI 产品验收。** 从头写表＋Plan 和固定表＋Plan 各走产品入口，在同版发布和同一玩家可见信息范围下核对。依次验证人机对战机器席、机机双席、按玩家提供的凭据调用副官。覆盖查证、预测、修订、故障恢复和费用记录。存完整可回放的对局；工程通过和策略效果分别记。
3. **F7 四臂复盘。** 同组冻结地图、军表、种族、对手、起始条件与随机口径，保留无学习基线。四臂是 WikiSkill 增量编辑、SkillOpt 用实战和重新采样的得失优化、Memento2＋ViSTA 检索场景经验并按可用视觉反馈做有界试验，以及三者混合。第四臂以外另设对照。每臂做「总结→实验→再总结」，由预先留出的完整回合/对局独立评价，登记成本、结果和实际策略选择变化。采用能处理图像的输入与模型验证 ViSTA；有文字回复不能算视觉成功。
4. **其余积压。** T27/S272 写表稳定性、T23/S248 对抗/地图/先手对照、T24 其余地图，以及 M25 真机和 PostgreSQL 实库按各自条件恢复。Wave4 Web 人人测试可先进行。
