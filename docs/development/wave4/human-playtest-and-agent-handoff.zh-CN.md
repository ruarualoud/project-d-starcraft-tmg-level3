# Wave4 人人对战更新

本分支只负责 Wave4 人人对战更新，按 Wave3 的更新模式补齐数据、规则、建军、房间、媒体和 Web 双席验收。其他同步开发线独立推进。当前分支是 `codex/wave4-web-pvp`，验收服务使用 5484，数据仅写入 `build/wave4-web/`；通过具名验收后提交并推送本分支。

W4-01 已冻结 U98/C88/R50 候选。W4-02 的 156 条逐 ID 差分完成，需新增游戏原子 18 个；前批累计 3 个及炮塔七条定义、原生回合与 Web 后继见[炮塔报告](turret-combat-wiring.zh-CN.md)。[两项 Virus 限制](virus-restrictions-wiring.zh-CN.md)新增 2 个，累计 5/18，原生与 Web 已验；继续 Universal Carrier、Virus 菌毯与新单位及其余来源。实时完成数与消费者以[接线账](../../../coordination/wave4/ability-wiring-progress.json)为准，组件通过不替代整版人人对战准入。

## 已核对的增量

初始官方写表器两次读取版本均为 U98/C88/R50，Wave3 基线为 U83/C84/R50。四个业务集合均读至末页。原件位置、字节长度、SHA256、记录 ID 与排除项见[差分索引](command-center-observation-2026-11-27.json)。候选发布清单已在 W4-01 冻结；后续来源准入复核保留独立记录，不覆盖该观察。

| 类别 | 实际工作量 |
|---|---|
| 单位 | 45 → 60。15 个新增，45 个旧单位记录的字段相同。新记录含英雄、专属变体、衍生物和弹体。写表可选性遵从各自记录和规则。 |
| 卡牌 | 49 → 59。8 张新增战术卡及 2 张新增势力卡（Stukov's Forces、Tal'darim）。13 张旧卡有强化说明变化。11 张明确了「紧接……之前」的时点，3 张将主体措辞改成「你的」，其中 Zerg Swarm 同时命中两类。例如 Armory 的 Vehicle Plating 在友方机械单位掷护甲骰前介入，Zerg Creep 约束己方写表选一张菌毯卡。按真实触发与受体分组取证。其余 36 张旧卡仅时间戳变化。 |
| 总规则、地图与任务 | 15 个规则章节字段相同；PDF/FAQ 若有新原件需单独比对。faction_cards 集合新增 7 个待审社区任务／部署，12 项旧记录只变了投票数，均不进入正式规则增量。 |
| 素材 | 对上述 15 个 ID 分别核对写表卡图、战场识别图、游戏通讯动画和事件语音。已认可的近似通讯头像和共享语音需显式标识。三族 BGM 沿用现有资源。 |

## 按 Wave3 模式执行

| 项目 | 工作与验收出口 | 当前范围 |
| --- | --- | --- |
| W4-01 来源与版本 | 冻结原件、SourceRevision、目录、ReleaseManifest；精确选版和跨版拒绝可恢复 | 已有候选与兼容证据 |
| W4-02 规则接线 | 新记录和旧卡变化逐 ID 接入实际消费者；核对触发、选择、支付、结算、清除及原生后继；签名、幂等和冷重放 | 正在补齐，见接线账 |
| W4-03 产品与媒体 | 大厅、手工写表、导入导出、房间工厂、地图任务和玩家查询使用同一发布；按新 ID 核对卡图、棋盘识别图、通讯头像、事件语音与 BGM | 局部 Builder 已接，整版待 |
| W4-04 Web 人人对战 | 500／2000 分双浏览器分别写表、建房、邀请、操作新机制、跨回合和重连；按受影响的规则补计分／终局分支 | 当前只有具名局部流程证据，整版待 |

每次从同一份冻结来源、实际军表或工厂状态开始，先命名失败的验收出口，再改必要消费者。玩家操作沿用 createEnvelope → legalSpace → preview → 真人确认 → apply → replay。成功断点保存后，只补验受改动影响的门；未变的 45 个旧单位和 15 个规则章节引用既有证据。

不同军表无法合法共存的组合用具名条件棋位，保留军表、阶段、几何和来源边界。局部规则验收不计成大厅完整选版或整版 Web 完成。共享基础设施的兼容读仅服务本次换版，不把旧版房间列为本轮开发任务或成果。

## 继续保留的准入边界

39 条来源阻断仍隔离：Archon 15 条、原生 Infested Goliath／Infested Siege Tank 23 条 CP 冲突、Alarak 阶段拼写 1 条。公开来源有冲突的记录解决后才准入。炮塔圆形 80 mm（60–100 mm）继续只作工程估算；正式物理几何另验。

付费模型、K3、AI 对局、复盘和生产发布继续暂停。本分支交付目标是可供玩家测试的本地 Wave4 人人对战。

接续顺序：Virus 卡效果 → Stukov／Infested Marine／Infested Trooper → 其他新增单位／势力 → 完整发布选择、Builder／大厅与媒体 → 两种规模的 Web 双席验收。
