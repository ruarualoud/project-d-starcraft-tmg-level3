## Executable Semantics

- Rules geometry sees the base only. Miniature pose, overhang and scenic basing
  are explicitly excluded; a flight stand uses its bottom footprint.
- Current official round bases and a rotatable rectangular Hydralisk base have
  exact canonical footprints.
- Measurements use inches and the nearest physical base/token/marker edges;
  touching bases measure zero and premeasurement is unrestricted.
- `Within` requires any target-base part to enter the range. `Wholly Within`
  requires the complete target base; a unit is Wholly Within only when every
  surviving model qualifies.
- Repositioning validates complete model placement, correct bases, board
  containment, overlap, enemy separation, the 3-inch Wholly Within test and a
  connected Coherency Link graph. Declared Access Points can carry a link
  through terrain.
- A placement casualty requires a content-hashed, rules-owned certificate that
  the candidate-position denominator is complete and contains zero legal linked
  positions.
- In-coherency state enables normal mission control/contest capability;
  out-of-coherency state disables it.
- Wobbly-model logical positions require agreement from all players and a
  visible position marker.
- The Leading Model nomination is cleared when the repositioning action resolves.
