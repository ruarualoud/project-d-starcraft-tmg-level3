## 完整模型工具边界

唯一空间查询目录：`packages/online-agent-session/spatial-query-contracts-v1.mjs`。表中的“确定”只覆盖列明的输入和规则范围，不是对所有未来局面的保证。

| 查询或工具 | 实际结论及边界 |
| --- | --- |
| `base_edge_distance` | 确定的底盘边缘距离；不推出 LOS、合法路径、占点或攻击。 |
| `within_and_wholly_within` | 确定的指定几何关系；不代替动作或任务规则。 |
| `space.inspect_relationships` | 关系/威胁为有范围估计；原生任务资格单独标确定或未知，保留双方 Supply、LOS、排除原因和控制结果。 |
| `space.solve_formation`、`legal_formation_options` | 同一个求解器和原生完整摆放校验；返回合法候选，不保证全局最优。候选比较自身的估计/未知不能提升为确定。 |
| `legal_asset_placement_options` | 当前能力域的合法资产位置；不保证以后安全或战略价值。 |
| `instantiate_parameterized_action` | 当前动作域及给定参数的原生准备计划；接受动作不证明其他未计算事项。 |
| `legal_full_path_movement` | 给定原生完整空间动作的合法路径和摆放；没有原生路径计划时明确未知。 |
| `coherency_after_candidate_placement` | 给定原生完整空间动作的连续性；不能拿另一个动作的实例化回执冒充。 |
| `action_specific_threat` | 指定射击/近战/冲锋的原生准备计划；冲锋保留路径证据，未掷骰前不保证成功或伤亡。 |
| `attack_probability` | 原生射击几何下的有界概率估计；不声称实现近战/冲锋概率，不保证伤亡。 |
| `fire_zone_exchange` | 有范围的射击交换、移动预测及显式未知；不表示整局效用或保证结果。 |
| `mission_marker_control` | 当前局面或原生空间候选后态的完整资格、双方 Supply 与粘性控制判定；仅表示若这些条件保持到 Cleanup 的控制，**不代表已经获得 VP**。 |
| Skill 读取 | 绑定当前加载 Skill/来源；策略内容是建议，不是动作合法性证明。 |
| 本局记忆读取 | 回复绑定同一房间、比赛、席位；保留行动、公开目的和计划延续，记录不代替规则查询。 |
| Planner / Action 提交 | 计划是模型建议；最终动作仍经当前 LegalSpace、原生实例化与权威执行。查询回执没有直接 Apply 权限。 |

退役名称 `intervening_model_or_terrain_blocking`、`line_of_sight_cover_and_elevation`、`objective_score_after_candidate_action` 不再广告为独立已实现工具。历史请求返回说明性的 unknown，改用真实原生动作计划/关系字段/任务控制查询。通用“候选动作后获得多少 VP”仍未实现，不以占点查询偷换。

共同回复校验覆盖 queryKind、房间/revision/state/match、席位、当前域及攻击者/目标等身份。模型输入压缩保留资格和未知字段，不再把无结论伪装成成功或零威胁。
