# Wave3 双人工大厅与共用房间验收

2026-11-25 · Ticket28 / T28-W3-11

上一轮的两间房经过正式规则工厂和房间服务，双方部署后停在 r6。移动和任务分差使用隔离后继验证。公开大厅未参与建房。上轮只核销 M22 和 M23，整场业务验收仍缺网页开局、双席操作、跨回合、终局与重新连接。

## 从玩家选择到原房重开

公开目录返回两种可选的 Wave3 双人配置。玩家选择规模、地图、任务、部署的已验证组合，以及双方示例或相同分数的自备军表。服务端解析配置 ID、军表和版本，生成原生开局、依赖清单、房间密钥和玩家席位。邀请链接将另一位玩家带入同一间房。旧房及此前的 AI 启动保留原入口。冷启动按保存的初始状态重建相同的规则版本，并逐房核对签名的绑定摘要。

## 哪些验收可以共用

| 编号 | 双规模主线可提供的证据 | 另需覆盖的断言 |
| --- | --- | --- |
| M01–M04 | 版本、双席军表、真实进场动作、保存和重连 | M01 要逐能力绑定；M02 要三族和势力组合；M04 要旧版房间和旧回执 |
| M05–M14 | 场上实际执行的动作都可记入相应项目 | 明确覆盖单位、装备、两规模运输、对手反应、伤亡等。互斥选择从动作前的已保存点分支 |
| M15–M19 | 同卡的开局、回合、计分、终局和重连可共用 | 每个规模和任务组合要有对应证据。Fire 的破坏和高地、Gather 的取得、Artefact 的拾取掉落要触发。任务开局已冻结，换任务须另一个开局或沿用已验原房 |
| M20–M23 | 三张部署卡及两尺度地图的既有签名与边界结果可复用 | 对应四项已通过 |
| M24 | 可用本次房间的同一 release、棋位、合法动作对照消费端 | Builder、Plan、Teach、MCP、实战决策、UI 须分别读取同一事实 |
| M25–M26 | 两个玩家经前端开局、交替、跨回合、终局、重开与回放 | Web 与原生端实际验证分别记录；M26 包含旧版本隔离 |

规则工程验收使用两位脚本操作者。对局中的 Pass 用于推进全局时序，不能据此推断军表强弱或 AI 策略效果。旧局、发布以及付费实验保持原状态。
