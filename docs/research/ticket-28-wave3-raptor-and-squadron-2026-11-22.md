# Ticket 28 / W3-10、11 Wave3 Raptor Strain 与 Squadron

原有普通空间移动把 Raptor Strain 写成 Kerrigan Swarm Raptor 的单位名特判，普通 Raptor 同有原文但拿不到权限。Wave3 改为读取冻结发布注册的能力 ID，同时给移动、冲锋地形准备及实际／假设编队使用。穿越权限仍须检查最终底盘是否合法。Squadron 以公开冻结文本绑定为 4 英寸，移动、近战、已有放置消费者使用同一规则投影。旧发布保持历史路径。

| 样本 | 原生验证结果 |
|---|---|
| 普通 Raptor | Standard 工厂认证 Size 4 墙段，18 模型军团实际 Move 5 英寸。相同编队通过 4 英寸检查，3 英寸失败。执行冷读回执相同。 |
| Size 边界 | 同一 Raptor 路径遇 Size 5 拒绝。Size 4 可穿越，但不能把模型停在墙内。实际和假设编队链接都允许跨 Size 4、拒绝 Size 5。 |
| Kerrigan Swarm Raptor | 六模型从平地移动到正式可站立高地，全部底盘读到相应高地支撑。没有声明入口仍通过；隔离关闭该能力后，同路径因缺入口被拒。 |
| 其余 Squadron | Hydralisk 与 Swarmling 的部署前规则投影读取 4 英寸。 |

样本采用工厂认证地形和明确预置的 Movement 棋位，首次布局按地图规则调整了任务点避让、象限和 Size 2 件数。其后使用真实编队、移动实例化和提交。旧版 V6 从既有档案重新构造，描述符逐字段相同。实际冲锋的骰子和伤亡、正式整局仍属于后续验收。本案零模型调用。

Standard 新增六条冻结定义的注册，现为 61/117，剩 56。当前 Skirmish 名册没有选择这六条，仍为 17/33，剩 16。Ticket28 整体 2/16。
