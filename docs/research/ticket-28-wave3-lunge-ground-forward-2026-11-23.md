# Ticket 28 / W3-11 · Lunge 同一前进量的最短绕行

冻结总规则 §4.5 要求绕过阻挡后继续原方向，等长路线由操作者选择。§8.5.3 规定普通 Move 最多可走速度。单模型使用 Lunge 仍可选择合法终点。多模型另需最短路线领队及其余模型尽量接近目标。

既有 4.993 英寸证据固定了起点和终点。若同时准许保持横向偏移，可以在向原方向推进相同距离时走得更短。新下界将终点放宽为垂直于原方向的整条直线，分别算一个确实挡住原方向的圆底盘的两侧切线、圆弧及继续前进段。忽略其余障碍和终点限制只会降低最小长度。候选仍由 Native Move 检查路径、摆位和方向。速度范围内若可能切换高差或使用特殊高差能力，撤回该下界。
