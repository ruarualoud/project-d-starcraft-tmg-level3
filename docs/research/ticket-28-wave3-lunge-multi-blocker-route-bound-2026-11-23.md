# Ticket 28 / W3-11 · Lunge 多障碍联合下界

继续使用冻结 U83/C84/R50 + FAQ 1.3 的同一个已付款棋位。开房、射击、付款和位移的旧检查点均已保留。此次只核验查询和规则原子，未提交新棋位。

## 实现

单独比较几个圆障碍只能取最大单项下界。新内核对选中的障碍圆取并集，把起终点、切点及圆周交点连为可见线段和不穿入其他圆的边界弧。最短路径使用连续几何长度。等长分支共享前驱图，避免展开组合路径。

Lunge 把原棋位上已验证底盘的保守禁入圆传给内核。最多取临近原直线的八个禁入圆，仍保留全部单障碍下界。省略其他底盘、地形和队形条件不会抬高路径下界。返回的线、弧和前驱图描述的是这个圆盘近似，正式位移仍需实际完整底盘、规则地形、方向和队形验证。

## 实测

- 对称重叠两圆的独立解析值为 8.367053 英寸，与联合内核一致。前驱图保留了顺时针、逆时针两侧的等长边。反向测量、添加重复和被包含的圆均得到同值。单圆与原 Charge 标量公式一致。
- 在同一实际 Hydralisk/Raptor 棋位，端点 (14.500, 5.300) 的单障碍下界是 5.646 英寸，联合为 8.560 英寸。另一个近速度上限的端点 (13.800, 8.000) 直线 4.888 英寸，两种下界均为 5.304 英寸。
- 首次尝试要求在 50 千分之一英寸的特定抽样网格找到「单障碍不排除、联合排除」的实际端点。该网格没有这个比较例。保留该结果，以上只声明观察到下界变紧。未据此修改规则或速度。
